A deterministic entry for [make.fun's Till Firmware Do Us Part bounty](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929). `main.py` writes one sentence to `/output/entry.txt`: a machine's own wedding vow, with a laugh in the situation and tenderness underneath.

## Run

```sh
python3 main.py
```

No network, no dependencies, no secrets. The output is UTF-8 text well under the 200-character gate.
